# SelfishNet v2 — Project Rules

- **Keep answers concise: no walls of text.** Lead with the answer; use short bullets or a table. Expand only when explicitly asked.
- **Do not rerun builds, tests, or publishing for a text-only/docs-only change.** Reuse existing verification; ask before any expensive rebuild.
- **If a request is ambiguous, ask before editing or rebuilding.** Do not guess and then spend a rebuild recovering from the misunderstanding.
- Read `AI_ENVIRONMENT_NOTES.md` first for project context and current state.
- Do not commit the root executables; they are local, git-ignored build artifacts.
- Keep `README.md`, `AI_ENVIRONMENT_NOTES.md`, and both guides current when behavior changes.
